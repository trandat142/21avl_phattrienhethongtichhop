# 21avl_phattrienhethongtichhop

Môn học hệ thống tích hợp

- 1. Tạo repository github-practice trên GitHub và thêm [README.md](http://README.md).

  2. Clone repository về ~/Documents/GitHub.

  3. Mở project bằng VS Code.

  4. Tạo file [Main.java](http://Main.java) và in dòng Hello GitHub.

  5. Kiểm tra thay đổi bằng git status và git diff.

  6. Tạo commit với thông điệp Add initial Java program.

  7. Push commit lên GitHub.

  8. Tạo branch feature/introduction.

  9. Bổ sung phần giới thiệu vào [README.md](http://README.md), commit và push branch.

  10. Tạo Pull Request, merge vào main và cập nhật nhánh main trên máy.

  11. Tạo một Issue mô tả chức năng sẽ phát triển tiếp theo.
